# 源码导读：优先级与通配符

## 核心文件：`mini_router/router.py:66-86` 与 `:110-138`

### 查找是「选最具体的」，不是「选第一个」（:66-:86）

静态 get 之后，动态表会扫完所有 method 相同且 `_match` 成功的模板，用 `_specificity` 更新 `best`。只在 `score > best[0]` 时替换——平局保持先匹配到的。

这里没有提前 `return`。第一条能匹配的动态路由不一定是对的。

### `_match` 里的通配符（:112-:116）

```
if seg.startswith("*"):
    name = seg[1:] or "path"
    params[name] = "/".join(request[index:])
    return params
```

通配符短路返回：剩余段（可以是空）全部属于它。所以 `/files/*path` 对 `/files/` 规范化后的 `['files']` 会得到 `path=""`。

### 打分（:128-:138）

4 / 2 / 1 的间距保证：多一个静态段，一定压过「少一个静态、多一个参数」的模板。你可以用别的正数，只要单调性相同：静态 > 参数 > 通配。

不要用「特殊路径写死」来消歧。分数才是可扩展的规则。
